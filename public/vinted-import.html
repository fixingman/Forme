Bring your followed brands into FORME

This experimental exporter reads brand names and links already loaded on your Vinted followed-brands page. It downloads a JSON file locally. It makes no network requests and reads no cookies or account credentials.

Easiest: paste your brand names

Open your followed-brands list in Vinted. Copy just the brand names, one per line, and paste them into Settings → Paste followed brands. Select Preview pasted brands, check the names, then merge.

Export a file without dragging

Use these steps in Dia, where you are signed in to Vinted. The in-app preview has no browser bookmarks bar.

  1. Copy the bookmark address below.
  2. Create a bookmark in Dia using its bookmark menu. Edit the bookmark’s address/URL, replace it with the copied address, and name it Export Vinted brands.
  3. Open your Vinted followed-brands page, then scroll to load your list.
  4. Activate the saved bookmark. Check the number of names and download the file.
  5. In FORME Settings, choose the file under Vinted brands export, review it and merge.

This exports loaded brand names only. It does not sync continuously or import saved searches, sizes, sellers or saved items. Vinted’s current page structure has not been verified in your Dia session because Dia blocked automated page reads. If no names are detected, nothing is exported.
